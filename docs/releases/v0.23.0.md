# v0.23.0 - Android : navigation au doigt et personnalisation complète

Cette version est consacrée à l'application **Android**. Rien ne change sous Windows et Linux.

## Naviguer d'une main

- **Tirer pour actualiser** : en haut d'une page, tirez vers le bas pour la recharger.
- **Gestes sur la barre d'outils** : glissez vers le haut pour voir tous vos onglets (vers le bas si la barre est en haut), à gauche ou à droite pour passer à l'onglet voisin.
- **Appui long sur Retour** : la liste des pages précédentes et suivantes de l'onglet, pour revenir plusieurs pages en arrière d'un coup.
- **Appui long sur le compteur d'onglets** : nouvel onglet, onglet privé, rouvrir l'onglet fermé, fermer l'onglet.
- **Onglets** :
  - glissez une carte sur le côté pour fermer l'onglet ;
  - **« Annuler »** apparaît après chaque fermeture ;
  - recherche parmi les onglets, affichage en grille ou en liste ;
  - confirmation avant de tout fermer.
- **Barre d'adresse** :
  - **suggestions de votre moteur de recherche** pendant la saisie (jamais en navigation privée, désactivables dans les Paramètres) ;
  - **recherche vocale** avec le micro ;
  - touches **www.**, **.com**, **.fr**, **.org**, **/** au-dessus du clavier.
- **Menu ⋯ en grille** : tout est visible d'un coup d'œil, les options activées (version ordinateur, sites en sombre) sont allumées. Nouveau : **Copier le lien**.
- **Page d'accueil** : vos **sites fréquents** (un appui long pour en masquer un), et en option une **horloge** avec une salutation.
- **Favoris** : renommez-les ou corrigez leur adresse, copiez ou partagez le lien. « Annuler » après une suppression.
- Les écrans s'enchaînent avec des **transitions animées**, et le téléphone **vibre légèrement** sur les appuis longs et les gestes.
- **Accessibilité** : taille du texte des pages, et zoom à deux doigts autorisé sur tous les sites.

## Personnaliser l'application

Un nouvel écran **Personnaliser** (menu ⋯ ou Paramètres), avec un aperçu qui suit vos choix :

- **12 thèmes prêts à l'emploi** : Aurore, Océan, Néon, Minuit, Forêt, Crépuscule, Braise, Noir pur, Lavande, Agrumes, Papier, et celui d'origine.
- **Couleurs** :
  - thème sombre, clair ou automatique, et **noir pur** pour les écrans OLED ;
  - couleur d'accent prise dans la palette **ou n'importe quelle couleur** (teinte, intensité, luminosité, ou code hexadécimal) ;
  - **teinte de l'interface** : les panneaux prennent un peu de votre couleur.
- **Fond d'écran** :
  - aucun, lueur, couleur unie, **dégradé** ou **photo** (assombrissement et flou réglables) ;
  - dégradés : 14 modèles, ou **sur mesure** avec 2 ou 3 couleurs, la direction de votre choix, linéaire ou radial, et même **animé** ;
  - le fond peut s'afficher **dans toute l'application** (onglets, paramètres, listes), avec des panneaux translucides.
- **Barre d'outils** : en bas ou en haut, compacte, normale ou grande, opaque ou effet « verre », et **jusqu'à 3 boutons de votre choix** (Retour, Avancer, Accueil, Nouvel onglet, Partager, Favori).
- **Formes** : coins carrés, arrondis ou ronds.
- **Page d'accueil** : titre personnalisable (ou aucun), nombre de colonnes, sections affichées.

Vos réglages actuels sont conservés. Si vous aviez choisi une image pour la page d'accueil, elle devient le fond « Image ».

## Installation sur Android

Si la **v0.22.0** est installée, **désinstallez-la d'abord**. Elle avait été signée avec une clé provisoire, et Android refuse d'installer une mise à jour signée autrement. C'est la seule fois : les versions suivantes s'installeront par-dessus, et la mise à jour depuis l'application fonctionnera. La désinstallation efface les onglets, favoris et réglages de la v0.22.0.

Téléchargez ensuite `Navigatueur-Android-0.23.0-arm64-v8a.apk`, qui convient à presque tous les téléphones récents.
