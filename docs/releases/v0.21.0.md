# v0.21.0 - Image dans l'image automatique, mode sombre forcé, aperçu des onglets

## Image dans l'image automatique

Une vidéo qui joue avec le son (YouTube, Twitch…) **continue dans une petite fenêtre** quand vous passez sur un autre onglet. Quand vous revenez sur son onglet, elle reprend sa place dans la page.

- Réglage : **Paramètres → Navigation → Image dans l'image automatique** (activé par défaut).
- Fermer la petite fenêtre met la vidéo en pause, comme d'habitude.
- Un onglet dont la vidéo est en image dans l'image n'est jamais mis en veille.

## Mode sombre forcé

Navigatueur peut **assombrir les sites qui n'ont pas de thème sombre**, avec le mode sombre intégré au moteur. Les sites qui ont déjà un thème sombre l'utilisent tel quel.

- Pour tous les sites : **Paramètres → Apparence → Mode sombre pour tous les sites** (désactivé par défaut).
- Site par site : menu **⋯ → Activer / Désactiver le mode sombre sur ce site**. Le choix vaut aussi pour les sous-domaines du site. On les retrouve et on les efface dans Paramètres → Apparence → Réglages par site.
- Dans une fenêtre privée, un choix fait pour un site n'est retenu que jusqu'à sa fermeture.

## Aperçu des onglets au survol

En laissant la souris sur un onglet, une carte affiche **une image de la page telle que vous l'avez laissée**, avec son titre et son adresse. Elle indique aussi si l'onglet est en veille, joue du son ou a le son coupé.

- Réglage : **Paramètres → Interface → Aperçu des onglets au survol** (activé par défaut). Désactivé, on retrouve l'infobulle avec le titre.
- Les images restent en mémoire et ne sont jamais enregistrées sur le disque. Un onglet pas encore ouvert depuis le démarrage n'a pas encore d'image : la carte montre alors seulement son titre et son adresse.

## Correction

- Fermer un onglet arrête maintenant vraiment sa page. Avant, elle pouvait continuer à tourner en arrière-plan (et à occuper de la mémoire) jusqu'à la fermeture de la fenêtre.
