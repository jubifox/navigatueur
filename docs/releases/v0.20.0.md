# v0.20.0 - Un seul fond d'écran, bouton Nouvel onglet au choix

## Le même fond partout

La barre d'outils et la colonne d'onglets reprennent maintenant **l'image de la page nouvel onglet**. Elle est alignée sur la page : chaque panneau montre la partie de l'image qui se trouve sous lui, comme si le fond continuait derrière l'interface.

- Réglage : **Paramètres → Apparence → Même fond pour la barre et les onglets** (activé par défaut).
- Vous préférez une image à part pour les panneaux ? Désactivez-le, puis choisissez-la dans « Fond des panneaux » (choisir une image désactive aussi le réglage automatiquement). Une image de panneaux déjà choisie avant cette version est conservée.

## Le bouton « Nouvel onglet » où vous voulez

**Paramètres → Interface → Bouton « Nouvel onglet »** :

- **En bas** (par défaut) : en bas de la colonne d'onglets, comme avant ;
- **Sous les onglets** : juste sous le dernier onglet ouvert, il suit la liste.
