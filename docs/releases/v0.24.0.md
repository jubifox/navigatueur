# v0.24.0 - Navigatueur peut être votre navigateur par défaut

## Windows

Navigatueur est maintenant **déclaré à Windows comme navigateur**. On peut donc le choisir pour ouvrir les liens des autres applications (Discord, mails, documents…) et les pages web.

- **Paramètres → Navigation → Navigateur par défaut** : le bouton « Choisir dans Windows… » ouvre directement la bonne page des réglages de Windows. Windows ne laisse aucune application se désigner elle-même, c'est vous qui choisissez.
- Il apparaît aussi dans la fenêtre « Comment voulez-vous ouvrir ceci ? » et dans « Ouvrir avec » pour les fichiers HTML, SVG et PDF.
- **Un lien ouvert depuis une autre application arrive dans un nouvel onglet** de la fenêtre déjà ouverte, qui passe au premier plan, même si elle était réduite ou dans la zone de notification. Avant, chaque lancement démarrait une deuxième copie du navigateur.
- La désinstallation retire proprement tout cet enregistrement.

L'enregistrement se fait à l'installation : il faut donc installer cette version avec son installateur (la mise à jour depuis l'application le fait).

## Android

**Paramètres → Navigation → Navigateur par défaut** : un bouton ouvre la fenêtre d'Android qui fait de Navigatueur le navigateur par défaut, ou à défaut les réglages des applications par défaut. La ligne indique si c'est déjà le cas.

## Linux

Rien ne change : le paquet .deb déclarait déjà Navigatueur comme navigateur.
